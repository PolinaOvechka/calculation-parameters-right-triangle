# calculation-parameters-right-triangle

Консольная программа на C# для вычисления параметров прямоугольного треугольника:
- Гипотенуза по двум катетам
- Площадь треугольника
- Периметр и радиус вписанной окружности

## Как запустить

### Через Visual Studio
1. Откройте файл `Lab_01_var4.sln`
2. Нажмите `Ctrl + F5` для запуска без отладки


### Пример использования
=== ВЫЧИСЛЕНИЕ ПАРАМЕТРОВ ПРЯМОУГОЛЬНОГО ТРЕУГОЛЬНИКА ===

ОПЕРАЦИИ:
1. Гипотенуза
2. Площадь
3. Периметр и радиус вписанной окружности
4. Выход из программы
Введите номер операции (1..4):
1
=== Вычисление гипотенузы прямоугольного треугольника ===

Введите катет a: 3
Введите катет b: 4

=== Результат ===

Гипотенуза = 5.00

## Особенности программы
1. Полная валидация ввода (проверка на число, положительность, пустой ввод)
2. Удобное текстовое меню
3. Форматированный вывод результатов с 2 знаками после запятой

### Требования 
1. .NET 6.0 или новее
2. Visual Studio 2022 (или любая среда с поддержкой C#)
